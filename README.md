# Bekaye Sora Manager

Je souhaite développer une application web SaaS ultra professionnelle nommée "Bekaye Sora Business Manager".

Cette application est destinée à l'entreprise Bekaye Sora, spécialisée dans la vente de produits cosmétiques de la marque 501.

Le slogan de la marque est :

"501 – Révélez votre éclat."

L'application doit être entièrement en français.

Je ne souhaite pas encore développer les fonctionnalités.

Je veux uniquement créer une structure professionnelle complète de l'application.

Le design doit être moderne, minimaliste, premium, rapide et intuitif.

Le propriétaire de l'entreprise n'est pas informaticien.

L'expérience utilisateur doit être extrêmement simple.

Palette de couleurs :

- Rouge (couleur principale)

- Blanc

- Gris très clair

- Noir doux

Créer une barre latérale gauche moderne contenant :

• Tableau de bord

• Produits

• Catégories

• Fournisseurs

• Entrées de stock

• Sorties de stock

• Inventaire

• Ventes

• Caisse

• Clients

• Employés

• Salaires

• Dépenses

• Rapports

• Statistiques

• Notifications

• Paramètres

Créer également :

- Une barre supérieure avec le logo Bekaye Sora.

- Le nom de l'utilisateur connecté.

- Une icône de notifications.

- Une icône de profil.

- Une recherche globale.

Chaque menu doit ouvrir une page vide avec un titre correspondant afin de préparer le développement des fonctionnalités.

Le design doit être responsive (ordinateur, tablette et téléphone).

Je souhaite une architecture propre, évolutive et prête à accueillir les prochaines fonctionnalités.
